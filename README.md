# Dear Mamdani

Weekly letters to Mayor Mamdani and a monthly scorecard of how New York is doing.

- Edit pages in `content/pages/`, letters in `content/letters/` (start from `_template.html`), then run `python3 build.py`.
- Scorecard figures live in `data/*.json` and are refreshed monthly.
- Set `PREVIEW = False` in `build.py` at launch.
